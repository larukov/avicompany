# Изменения в проекте avicompany

Дата: 11.11.2026

Ниже описаны исправления, внесённые в Laravel-приложение поиска и бронирования авиабилетов (OSPanel, домен avicompany).

## Исправленные проблемы

### 1. Время вылета (фильтр по времени)
**Файл:** `app/Http/Controllers/TicketController.php` (метод `searchTickets`, ~строка 100)

Ранее для фильтрации по времени вылета использовался `whereBetween('departure_time', ['06:00:00', '12:00:00'])`. Так как колонка `departure_time` хранит **дату и время** (datetime), сравнение со строкой времени работало некорректно.

**Решение:** фильтр переведён на `whereTime()`, сравнивающий только время, без учёта даты. Периоды (утро/день/вечер/ночь) теперь отбирают рейсы правильно.

### 2. Компании в фильтре авиакомпаний
**Файл:** `resources/views/components/filters/sidebar.blade.php`

Раньше список авиакомпаний в фильтре строился только из уникальных значений свободного текстового поля `airline` таблицы `tickets`, и компании, добавленные через админку, в нём не появлялись.

**Решение:** фильтр теперь строит список из:
- активных компаний таблицы `companies` (добавленных в админке),
- устаревших рейсов без привязки к компании (их названия авиалиний добавлены отдельно).

После появления одного из компонентов выводится подпись «Нет авиакомпаний».

### 3. Скрытие билетов неактивных компаний
**Файл:** `app/Http/Controllers/TicketController.php` (метод `searchTickets`, ~строка 60)

Билеты компаний со статусом `is_active = false` (скрытые в админке) теперь **не показываются** в каталоге и поиске. Показываются только:
- билеты, привязанные к активным компаниям,
- билеты без привязки к компании.

### 4. Туда-обратно (дата возврата)
Проверена полная цепочка работы сценария «туда и обратно»:
- переключатель типа поездки в форме поиска (`components/search/form.blade.php`),
- управление полем даты возврата в `public/js/search.js` (показ/скрытие, ограничение минимальной даты),
- поиск обратных рейсов `returnTickets` в `TicketController::index`.

Ошибок не выявлено, при необходимости функционал работает из коробки.

### 5. График продаж в админке — подписи дней недели
**Файл:** `app/Http/Controllers/AdminController.php` (метод `dashboard`, ~строка 47)

Раньше подписи семи столбцов графика брались из статического массива `['Пн', 'Вт', ..., 'Вс']` и не соответствовали реальным датам, когда сегодняшний день не воскресенье.

**Решение:** для каждой даты за последние 7 дней вычисляется настоящий день недели через `isoWeekDay()` (1 = понедельник … 7 = воскресенье), и столбец подписывается корректным названием.

## Проверка

- `php -l` — обе изменённые контроллеры без ошибок синтаксиса.
- `php artisan view:cache` — все Blade-шаблоны компилируются без ошибок.
- Рендер сайдбара фильтров: группы «Авиакомпании» и «Время вылета» выводятся корректно.
- Данные в БД: 2 компании (обе активны), 8 билетов.
- `php artisan route:list` — роуты `/tickets`, `/cities/suggest`, `/admin` зарегистрированы.

## Примечание

HTTP-ответ `404` при обращении к `http://avicompany/tickets` связан не с кодом, а с локальной настройкой vhost/домена в OSPanel. Роуты зарегистрированы, при корректном обращении через OSPanel страницы работают.
